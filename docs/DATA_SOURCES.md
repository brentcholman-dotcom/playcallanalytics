# Data Sources

## Historical Data
- **nflfastR**: Play-by-play data, including win probabilities and expected points. Accessed via `nfl_data_py`.

## Live Data
- **ESPN Hidden API**: Used for real-time scoreboard and play-by-play updates.

## Environmental Data
- **OpenWeatherMap**: Live weather data by stadium coordinates.
- **Stadium Noise**: Manual dB input or proxy-based estimation from stadium base ratings.

## Injuries
- **NFL Injury Reports**: Weekly reports for pre-game state.
- **In-Game Tracker**: Manual input via CLI for mid-game injuries.
